# 星隙突击 · STAR RIFT

浏览器中的原创 3D 竖版射击肉鸽游戏。第一作战区域为云海防线，第二作战区域为失控轨道。每局生成两张各 13 个节点的航线图，探索、战斗、补给与构筑贯穿两个区域，最终在第二层寻找随机位置的「天穹裁决者」母舰并击败三个阶段的 Boss。

## 启动

需要 Node.js 22.12 或更高版本，建议使用开启硬件加速的 Chrome 或 Edge。

双击 `启动游戏.cmd`，会检查依赖、在后台启动本地服务并打开浏览器。也可以在当前目录运行：

```powershell
npm install
npm run dev
```

电脑浏览器打开启动脚本显示的地址，默认是 http://127.0.0.1:5173/ 。服务同时支持局域网访问：手机、平板与电脑连接同一 Wi-Fi 后，在设备浏览器中打开脚本显示的 `http://电脑局域网IP:端口/`。脚本会复用已运行的局域网游戏服务；5173 被占用时使用 5174。电脑需保持游戏服务运行。游戏不依赖远程素材或付费接口，依赖安装完毕后，游戏内容和声音可以离线运行。

## Cloudflare Pages 线上游玩

任何人都可以直接在浏览器打开线上游戏，无需下载源码或本地部署：

https://mest-dxp.pages.dev/

更新线上版本时，在项目目录运行 `npm run build`，再使用已登录的 Wrangler 上传生产构建：

```powershell
npx wrangler pages deploy dist --project-name mest --branch main
```

部署到 Cloudflare Pages 的内容是 `dist/` 静态文件。在线游戏不要求玩家安装 Node.js；Node.js 和 npm 只用于本地开发、构建及发布。

生产构建：

```powershell
npm run build
npm run preview
```

## 操作

| 操作 | 按键 |
| --- | --- |
| 飞行移动 | WASD / 方向键 |
| 无敌机动 | Shift，默认 3.5 秒冷却 |
| 主动技能 | E |
| 切换武器 | Q / 数字 1–8 |
| 精确移动、显示受击轮廓 | 按住 Ctrl |
| 手动射击 | 空格 / 鼠标左键 |
| 自动射击切换 | F / HUD 按钮，默认开启 |
| 查看装备 | Tab |
| 暂停、继续、返回 | Esc |
| 航线、商店与事件 | 鼠标；航线节点支持 Tab 聚焦后 Enter |

所有武器使用无限弹药，持续按各自射速开火，不会耗尽弹药、换弹或因过热停止。自动射击默认开启。主要攻击方向为屏幕上方。失去窗口焦点会自动暂停，恢复后点击继续。

手机和平板在战场任意位置按住并拖动即可移动战机。按下时保持原位，拖动位移在下一次逻辑更新直接应用，松手后停止；不需要移动轮盘，也不再受飞行速度限制而缓慢追赶手指。位移按实际战场投影转换，横竖屏均保持跟随关系，保留战场边界。默认自动开火，另一根手指可同时切换武器、闪避、使用技能或按住手动开火。「精细」将手指位移灵敏度降至 45%，不增加追赶延迟；键盘精细移动仍降低飞行速度。装配按钮用于查看装备；航线、商城、事件和奖励直接点选。快速拖动跨过敌方炮弹或正在发射的激光时仍检查移动路径上的受击，预警光束不会造成伤害。

手机竖屏底部使用两行紧凑按钮：武器、装配和自动开火在上行，闪避、技能、开火和精细移动在下行。平板和横屏将按钮整合为一行，操作区不覆盖战场。切换方向和调整窗口不会重新开始游戏；旋转、暂停、进入菜单和触控中断时会清理按住状态，避免战机持续移动。战斗视野完整保留可移动区域，并兼顾设备安全边距与浏览器工具栏高度。

画质默认使用「高清」，按屏幕实际像素密度渲染（最高 4 倍），并对支持的设备启用战场多重采样抗锯齿。触控设备仍有 600 万渲染像素的总预算，以控制大尺寸平板的显存占用。在主菜单或战斗暂停菜单进入「游戏设置」，可即时切换「高清 / 均衡 / 流畅」，浏览器会记住当前设备的选择。「均衡」最高 2 倍；「流畅」在手机上沿用原来的 1.25 倍分辨率，适合发热或运行吃力时使用。三档保留相同的战场范围、三维模型、阴影和泛光。

「游戏设置」另有「精简 / 标准 / 丰富」特效强度、0–100% 镜头震动、0.5–2.0 倍触控灵敏度，以及音乐和音效音量。默认丰富特效、100% 震动、1.0 倍灵敏度。设为 0% 可关闭震动；精简特效减少装饰尾迹、光晕和碎片，仍显示实体弹体、敌方预警、技能主体与保护力场。所有选项即时生效并保存到当前浏览器，禁用存储时仍可在本次游玩中调整。「恢复默认设置」同时还原画质、特效、操作和声音。

视觉采用未来科技航空风格。8 种武器分别具有金属弹芯、散射镖弹、贯穿长钉、机械制导导弹、分段束流、带电光节点、旋转刀翼和带能量框架的等离子主炮，并有短促枪口闪光。实际射速、弹道、伤害、追踪和贯穿规则保持原有设计。僚机与模块协同的额外炮弹也使用对应的新版弹体。

玩家和敌方弹体的尾迹使用动态气流效果，已取消原来的三角形尾迹和导弹的几何火焰。机炮、散射弹、导弹和敌方炮弹显示浅色热核、红橙焰层、翻卷与断续的火舌、稀疏火星及淡烟；轨道炮、束流、电弧、刃盘和等离子炮保留各自的武器颜色，使用流动能量尾流。尾焰从弹体尾部沿飞行反方向喷出，转向时跟随弹体，暂停时冻结。不同炮弹拥有独立变化相位，移动不会重置或逆转气流。可见轮廓由连续变化的密度和温度控制，不露出硬边的几何外形。多层尾焰合并为一次绘制，共用几何体和材质；精简特效关闭尾焰，保留弹体和受击提示。

敌方炮弹保持红橙危险色，并按发射敌机区分：侦察截击弹有尖芯和双导轨，编队散射弹有三段镖芯，炮艇使用分段铜色弹体，重装机使用厚装甲节段，母机使用双脉冲弹芯，精英使用旋转能量笼，Boss 使用分段等离子核心和红色导能轨。Boss 两侧炮台及重型弹幕同样使用 Boss 身份。实体弹体、弹速、伤害及连续碰撞尺寸保持一致；光晕和淡出尾迹不参与受击判定。每颗敌弹的硬件合并为一个网格，并复用几何体和材质；精简特效隐藏尾迹和光晕，仍保留完整危险弹体和不同类型的结构。

进入 Boss 航道时，战场中央显示红色 DANGER 横幅与「天穹裁决者」名称，并播放三次短促警报。约 2 秒预警后自动开始战斗；预警期间冻结移动、双方开火、扣伤、保护与冷却计时，不消耗入场保护，也不能提前释放技能。暂停或打开设置会冻结预警，恢复后从剩余时间继续，已经开战后再暂停不会重复预警。警报服从音效音量与静音设置；精简特效仍保留完整危险提示。横幅位于战场内，不遮挡暂停和触控操作栏。

电磁脉冲使用分层六边形能量扫掠与定向火花；棱镜护盾显示聚合晶片和持续多面体防御罩；轨道轰炸显示多处垂直能量击打和碎片爆闪；蜂群支援显示无人机组装与出列轨迹，支援持续 12 秒。闪避和连锁电弧也使用新的速度残影与立体闪电。技能数值、冷却和保护时长保持不变。

玩家战机、无人机、7 类敌机与 Boss 加入分层装甲、导能通道、反应器和各自的武器结构；残骸、运输箱、燃料舱、地雷升级为科技设施。云海防线有浮空平台、扫描装置、航行拱架和多层云带；失控轨道有星空、远处行星、轨道环、太阳能翼与空间设施。静态结构按材质合并绘制，场景和短期特效结束后释放临时资源。玩家实体轮廓和敌方胶囊弹仍共用碰撞定义。

敌机击毁使用科幻能量炸裂特效：短促的蓝白亮核、定向飞散的能量火花、翻转并迅速淡出的金属碎片，普通爆炸约 0.6 秒结束。重型敌机和 Boss 的炸裂规模更大，但有尺寸与粒子数量上限。导弹爆炸使用同一套效果并保留武器色彩；爆炸及命中反馈不再绘制扩散圆圈。火花和碎片通过实例化绘制，效果结束后释放临时资源。

命中敌机时，伤害数字从实际命中位置短暂上浮，并把同一目标在极短时间内的连续命中合并成一个易读数值；数字取实际扣除的生命值，致命命中不会显示超过剩余生命的伤害。普通敌机在受伤后显示约 2.2 秒的投影血条，精英血条更宽且使用高亮色；未受伤或已击毁的普通敌机不显示血条。Boss 只保留战斗顶部的 Boss 血条，避免重复遮挡。数字和血条绘制在独立的高密度透明画布上，跟随战场画布的尺寸、设备像素比和暂停状态，在手机、平板与桌面保持清晰且不接收触控。

## 航线与构筑

- 橙色节点为可以前往的空域。未知节点在抵达邻近空域后揭示。
- 已清空的节点可以直接回访，便于返回分叉点选择其他路线。商店回访时保留原商品和购买状态。
- 每层完成至少三处普通或精英战斗后，出口或 Boss 航道解除封锁；无需清空全部节点。
- 隐藏空域为可选支路，可通过侦察雷达、特殊事件或击毁部分运输箱发现。
- 补给仓可能需要通行芯片。没有芯片时仍可回收外围物资，不会锁死流程。
- 商店出售武器、装备、技能、修复和通行芯片。进入第二区域会修复部分装甲、补充护盾并提供物资。
- 8 种武器：双联机炮、散射炮、轨道炮、追踪导弹、脉冲激光、电弧炮、回旋刃盘、重型等离子炮。
- 12 种被动模块和 4 种主动技能，可组成四组武器协同：集束协议、雷暴回路、交叉火力、棱镜折射。
- 运输箱可掉落修复、芯片与货币；装甲残骸阻挡双方弹道；燃料桶和地雷会产生范围爆炸。
- 红橙弹幕是敌方攻击。激光从敌机前方炮口发出，预警和光束随发射器移动，击毁发射器即可消除光束；伤害范围与可见光束一致。敌方炮弹按实体长度与战机的机身、机翼轮廓进行连续碰撞检测，高速炮弹和移动交会不会漏判，光晕与尾焰不计入碰撞。精细移动时显示实际受击轮廓。命中先扣护盾，不足部分扣机体；入场、闪避、力场技能和受击后的保护状态显示蓝色力场与 HUD 提示，受击保护持续 0.85 秒，保护时碰撞到的炮弹会被拦截。

## 项目结构

| 文件 | 内容 |
| --- | --- |
| `src/game.js` | 战斗、碰撞、敌人、Boss、资源、商店、事件与游戏状态 |
| `src/content.js` | 武器装备内容、种子随机数、随机航线生成 |
| `src/renderer.js` | 原创程序化 3D 模型、两套场景、光影和战斗特效 |
| `src/explosion-effects.js` | 科幻能量爆炸、实例化火花与碎片、生命周期及资源清理 |
| `src/weapon-visuals.js` / `src/skill-visuals.js` | 8 种弹体、枪口、4 种技能、闪避与连锁电弧 |
| `src/hostile-visuals.js` | 按敌机区分的红橙弹体、共享胶囊轮廓和合并硬件 |
| `src/projectile-plumes.js` | 动态燃烧与能量尾流、气流扰动、独立相位及共享渲染资源 |
| `src/combat-feedback.js` | 命中伤害数字、普通敌机临时血条、Boss 血条避让及高密度战场叠加层 |
| `src/future-models.js` / `src/future-environments.js` | 未来科技战机与设施、静态结构合并、两区环境 |
| `src/preferences.js` / `src/settings-ui.js` | 设置校验、保存、恢复默认与设置页面 |
| `src/ui.js` / `src/style.css` | 航空仪表风界面、航线图与菜单 |
| `src/touch-controls.js` | 战场拖动移动、多指技能与射击操作、横竖屏切换清理 |
| `src/audio.js` | 原创 Web Audio 分层配乐与合成音效 |
| `src/main.js` | 输入、固定步长模拟、画面和声音接入 |

模型、纹理、界面与声音由代码生成，无外部游戏素材、完整游戏模板或运行时 CDN。图形使用 Three.js，开发和构建使用 Vite。

## 验证

```powershell
npm test
npm run test:smoke
npm run test:laser
npm run test:damage
npm run test:responsive
npm run test:graphics
npm run test:explosions
npm run test:presentation
npm run test:controls
npm run test:boss-warning
npm run test:plumes
npm run test:feedback
npm run test:browser
```

逻辑测试检查每区 2,000 个种子的航线、关键目标解锁前可达性、交易、装备、技能、掩体、进度、Boss 与重开。短浏览器测试检查菜单、交易、暂停及不同窗口尺寸。完整浏览器测试通过实际菜单点击与键盘输入游玩两区，保存截图与报告到 `test-results/`，不添加无敌、跳关或直接设置胜利。

激光回归测试使用实际引擎和三维渲染器的独立复现场景，检查移动中的炮口、光束、伤害起止位置以及发射器销毁后的清理，并覆盖 Boss 三处激光炮口。

受击回归测试在桌面与手机浏览器中运行独立炮弹复现场景，检查实体弹形与碰撞数据一致、机翼命中、护盾与机体的扣除数值、高速穿越、保护期间的拦截与提示、保护结束后再次受伤、光晕擦过和致命命中。数值与场景初始化只用于选择被测状态，碰撞和界面通过正常游戏帧更新；报告保存为 `test-results/damage-report.json`。

响应式测试使用 Chromium 的移动设备与多点触控模拟，检查手机、平板横竖屏及桌面尺寸的界面、战场投影、安全边距和触控命中范围。通过正常菜单出击、购买和进入战斗，实际发送多手指触控事件，验证任意位置按下不瞬移、上下左右相对拖动、停留与松手、第二根手指不抢占移动、闪避后不回拉、技能、切换武器、手动持续开火、取消触控、暂停与旋转。每种手机／平板尺寸另验证拖动位移与战场投影一致。各菜单的尺寸检查另使用明确标记的显示场景，不作为完整通关证明。

画质测试检查高分屏默认高清、后处理抗锯齿、三档实际分辨率、切换前后的战场投影一致、刷新后的设置保存、横竖屏与平板像素预算，以及浏览器禁用存储时仍能切换。固定显示场景的截图仅用于画面对比，不作为完整通关证明；报告为 `test-results/graphics-report.json`。

爆炸专项测试通过实际炮弹命中验证击毁触发，并检查亮核、定向火花、碎片衰减、命中反馈不叠加圆圈、暂停与恢复、不同敌机与 Boss 的尺寸边界、连续爆炸绘制预算和资源释放。截图来自独立显示场景，不作为完整通关或实体手机性能证明；报告为 `test-results/explosion-report.json`。

设置与视觉专项测试使用实际设置控件、键盘和触控事件，检查设置保存、默认还原、不同灵敏度、不良存储兼容、8 种实际发射弹体、无人机与协同炮弹、各类模型、4 种技能的数值和暂停、精简特效的战斗提示，以及重复激活和场景切换后的资源释放。报告为 `test-results/presentation-report.json`，另有两区、武器与模型展示截图。这些明确初始化的独立场景用于验证外观和功能，不作为最新完整通关或实体设备性能证明。

触控响应与敌弹专项测试在六种手机和平板尺寸发送快速反向拖动，检查接收到输入的首次逻辑更新就到达目标，同时验证同帧移动／松手、精细移动和取消。敌弹检查实际发射类型、Boss 两侧炮台、七种结构、朝向、实体尺寸、精简特效及密集弹幕资源复用；报告为 `test-results/controls-report.json`。

Boss 预警专项测试从已解锁的独立航线场景实际点击 Boss 节点，验证预警、冻结、暂停、设置、声音静音、开战与重开，以及七种触控尺寸和桌面布局；报告为 `test-results/boss-warning-report.json`。这些专项场景不作为最新两区完整通关或真机触控延迟证明。

尾焰专项测试比较实际 GPU 渲染像素，验证火焰随时间流动、暂停冻结、恢复、不同炮弹的独立相位、移动不重置气流、八种实际发射弹体的尾焰朝向、危险色与能量色、精简特效及 140 发弹幕的渲染资源复用。报告为 `test-results/plume-report.json`，另保存原游戏近距离渲染的静态与动态预览；这些独立外观场景不作为完整通关或真机性能证明。

伤害反馈专项测试在手机尺寸与桌面尺寸的 Chromium 中，通过实际友方炮弹命中和引擎伤害事件检查扣除值、命中位置、连续命中合并、数字先消散后血条隐藏、击毁后的清理、Boss 仅保留顶部血条、敌方炮弹不生成友方伤害数字以及移动端边界和无横向溢出。报告为 `test-results/feedback-report.json`，手机截图为 `test-results/feedback-phone.png`；该专项不作为最新完整两区通关或实体手机性能证明。

浏览器测试默认使用本机 Chrome，可通过 `CHROME_PATH` 指定其他 Chromium 浏览器路径，通过 `GAME_URL` 指定运行地址。完整游玩测试需要数分钟。
